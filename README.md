## Run it

```sh
python3 main.py            # writes entry.png to $MAKEFUN_OUTPUT_DIR (default: out/)
```

`main.py` is stdlib-only: it validates the bundled `entry.png` (PNG signature,
1024×1024 IHDR, well-formed IEND trailer, ≤ 1 MiB) and copies it byte-for-byte.
`draw.py` regenerates `entry.png` with Pillow.
